# Timeline strand experiments

Standalone pages (open them in a browser, no build needed) from the exploration of how the Versions timeline lines should look, in the order they were made:

1. `lines.html` – first attempt at flowing, rainbow energy along the lines.
2. `lines2.html` – a more complex animation, reached from page 3 as a comparison.
3. `lines3.html` – continuous strands of light instead of visible energy points.
4. `lines4.html` – the soft-glow version that led to the WebGL layer.

The result is `frontend/src/components/builder/StrandLayer.tsx`. These files are kept as a record of the options that were tried, and are not part of the app: they live outside `frontend/public` so they are never served.
