# Instant reference-prompt archive

Reverse-engineered Midjourney-style prompts from real printed MTG Instant art, gathered by viewing actual card images (Scryfall art crops) across rarity/price/popularity/alt-art samples. Use this archive as a lookup BEFORE the Concept Engine (SKILL.md step 0.5): find the 1-3 entries closest to the new card's register + subtype, read them as concrete structural anchors (how real art actually solved this register), then build a genuinely new, card-specific concept on top — never copy an entry's content verbatim onto a different card.

Each entry: card name | register | subtype | rendering style | reverse-engineered prompt.

Target density for every entry (set by the 2026-11-09 LTR/SOI pass, applied to the original 65 in a follow-up pass the same day): a real generation-ready paragraph, not a one-clause label — subject material/texture, pose/action, setting with its own texture, camera angle or vantage, a named palette, the light source and its quality, a mood word, and the explicit style line, in that rough order. All 142 entries now match this density (roughly 70-120 words each). Keep new entries at this density — a one-clause label is no longer the house style for this file.
